## 🧠 학습 내용
1. **기본 문법**
   - **변수 선언 및 데이터 타입**: `var`, `let`, `const`를 사용한 변수 선언과 숫자, 문자열, boolean 등의 자료형 타입 이해
   - **연산자**: 산술, 비교, 논리 연산자 활용
   - **조건문**: `if-else` 및 `switch` 문을 통한 흐름 제어
   - **반복문**: 루프를 사용한 반복 처리

2. **함수**
   - **함수 선언 및 호출**: 함수 선언문과 표현식을 통한 함수 정의 및 호출
   - **매개변수와 반환값**: 함수의 입력과 출력 처리
   - **스코프**: 전역 및 지역 스코프 이해
   - **익명 함수와 화살표 함수**: 간결한 함수 표현

3. **객체와 배열**
   - **객체 생성 및 접근**
   - **배열 생성 및 메서드 활용**
   - **객체와 배열의 반복 처리**

4. **DOM 조작**
   - **요소 선택**: `getElementById`, `getElementsByClassName`, `querySelector` 등등을 사용한 DOM 요소 선택
   - **이벤트 처리**: `addEventListener`를 통한 이벤트 리스너 등록
   - **요소 생성 및 추가**: `createElement`와 `appendChild`를 사용한 새로운 DOM 요소 생성 및 추가
     
5. **Window 내장 객체**
   - **`setTimeout`과 `setInterval`**: `setTimeout`을 사용하여 일정 시간 후에 함수를 실행, `setInterval`을 통해 일정 간격으로 함수를 반복 실행
   - **`alert`, `prompt`**:  `alert`로 경고 메시지를 표시, `prompt`를 통해 사용자 입력을 받기
